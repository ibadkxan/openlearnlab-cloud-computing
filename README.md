🌌 Open Learn Lab

One website. Eight experiences. Endless ways to explore.

Ever wanted a place where you could create something, explore the universe, test your reflexes, or simply relax for a while?

That’s the idea behind Open Learn Lab — a browser-based playground where creativity, curiosity, and fun come together.

I’m building this project as part of my Cloud Computing Solo Project, exploring how to develop a modern web application that can eventually be deployed to the cloud.

Instead of making another website that does just one thing, I wanted to bring together different experiences in one place. Something people can open in their browser, explore at their own pace, and actually enjoy using.

Welcome to Open Learn Lab. 🚀

⸻

✨ What’s Inside?

Eight experiences. Eight different ways to spend your time.

🎨 CREATE — Make something of your own

Experience	What you can do
🎨 Flow State	Experiment with generative visuals, movement, colours, and flowing patterns. Create something unique and export your artwork.
🎧 Sound Garden	Explore four listening modes — Calm, Steady, Sleep, and Read — with adjustable volume.
✏️ Draw Studio	Get creative with a digital canvas, experiment with your drawings, undo changes, and export your work.

🌌 EXPLORE — Get curious

Experience	What you can do
🪐 Gravity Room	Compare gravity on different worlds, explore an illustrative solar system, and experiment with a simplified universe simulation.

🎮 PLAY — Challenge yourself

Experience	What you can do
⚡ Quick Reflex	Test how quickly you react when the signal appears.
🧠 Memory Match	Flip cards, find matching pairs, and see how many moves you need.
🔷 Pattern Pulse	Watch a sequence of visual signals and try to reproduce it from memory.
🔤 Word Sprint	Race against the clock and find words using the available letters.

The goal is simple: every experience should be easy to start, enjoyable to use, and different enough to make you want to try another.

⸻

🛠️ Built With

Here’s what’s powering the project:

* React — building the interface and interactive experiences.
* Vite — fast development and production builds.
* JavaScript — application logic and interactions.
* CSS — layouts, animations, and visual design.
* HTML Canvas — interactive graphics and drawing.
* Web Audio API — generating sound directly in the browser.
* Lucide React — interface icons.

One of the things I wanted to focus on was keeping the experiences modular. Each feature should be possible to improve independently without having to rebuild the entire application.

💻 Run It Locally

Want to explore the project on your machine? Here’s how to get started.

What you’ll need

* Node.js (a recent LTS version is recommended)
* npm
* Git

1. Clone the repository

git clone https://github.com/YOUR-GITHUB-USERNAME/open-learn-lab.git
cd open-learn-lab

Replace YOUR-GITHUB-USERNAME with your GitHub username.

2. Install dependencies

npm ci

3. Start the development server

npm run dev

Open the local address shown in your terminal and start exploring.

4. Build the project

npm run build

This creates the production build in the dist/ directory.

☁️ Why This Is a Cloud Computing Project

Open Learn Lab is my Cloud Computing Solo Project. The current version focuses on building the frontend and organizing the application so it can be extended as the project develops.

The next step is to deploy the application through AWS Amplify and verify that the production version works correctly.

I’m also keeping future improvements in mind, including:

* Connecting a backend through REST APIs.
* Adding persistent storage where it makes sense.
* Saving user creations and preferences.
* Tracking game scores and progress.
* Expanding the playground with more experiences.

The current version is frontend-only. It does not yet require a database or backend service.

I want to build the application in stages, understand how each part works, and introduce cloud infrastructure when it is actually needed.

⸻

🧪 A Few Things Worth Knowing

* Sound Garden currently generates filtered noise in the browser. It doesn’t yet use recorded rain, ocean, or other environmental soundscapes.
* Gravity Room is an interactive learning experience, not a professional physics simulator. Its solar system and gravitational sandbox use simplified models.
* Game progress and preferences are not currently stored in a database.
* The project is still evolving, so some experiences will receive further improvements.

I’d rather be clear about what works today and improve it step by step than claim features that aren’t implemented.
